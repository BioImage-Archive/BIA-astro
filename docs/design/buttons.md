# Application button geometry

Rectangular application actions use square corners. The shared
`--bia-button-radius` token lives in `src/styles/button-shape.css`, imported by
the four document layouts. Wrapper layouts inherit it through their parent.

Add `bia-button` to native action buttons and button-styled navigation links,
including controls created by client renderers. Preserve existing variant
classes, attributes and event hooks. Do not add a competing local or inline
radius. Search and gallery radio-selection faces and their group
containers use the same token without changing their native input/label relationships.

```html
<a class="vf-button vf-button--primary bia-button" href="/bioimage-archive/studies">
  Browse studies
</a>
<button class="vf-button vf-button--primary bia-button" type="button">
  Copy URI
</button>
```

The shape rule does not define colors, sizes, shadows, focus or selection.
Primary and secondary variants retain their roles. Navigation uses an anchor;
commands use a button. Form submit/reset actions retain the appropriate type.

Plain links and text-style commands, filter chips, arrow glyphs, circular
tooltip controls, disclosure summaries and navigation icons remain separate
families. Cards, dialogs, images and input fields retain their own geometry.
Shared EMBL-EBI chrome and external viewer interfaces have separate styling
ownership.

Table pagination inside BIA uses the same token through a `bia-table-controls`
ancestor, preserving DataTables' focus, disabled and current-page feedback.
Apply this scope around study viewable-image tables, spatialomics file tables,
benchmarking and model-prediction tables, input-image and specimen-track tables,
AI-ready study tables and the volume-EM table view.
The shared rule covers the current DataTables paging buttons and the legacy
pagination markup generated by the study table. It survives paging, searching
and table reinitialization without adding classes to vendor-generated nodes.
Pagination outside this explicit scope is unchanged. Text-style file-path
Expand/Collapse commands remain a separate family.

On the Spora dataset browser, row `Cite`/`Download` and `Clear filters` are
text-style commands. They keep their transparent, unboxed appearance. The
rectangular `Copy`/`Copy BibTeX` and `Close` buttons inside its dialogs use the
shared square geometry. Dataset type/modality badges and the dialog container
remain rounded; they are not action buttons.

`npm test` includes compiled rendering checks for shared styles in all four
layouts, gallery card cascade, newsletter navigation, search submission,
selected file views, search view selectors and dialog class forwarding.
For changes to the token or adoption, also check
actual rendered pages at narrow and desktop widths, keyboard focus,
hover/pressed states and controls regenerated after filtering. Check all four
corner radii; a resting screenshot alone does not verify the cascade.

Navigation links do not wrap command buttons, and command buttons do not wrap links. Keep viewer metadata IDs unique across repeated panes and preserve existing annotation-carousel hooks. Gallery/card rules may use `var(--bia-button-radius, <existing radius>)` so their prior shape remains when the application theme is absent. Do not change JavaScript selectors when adding the CSS hook to a control. The actual file-view handler is exercised by a regression test.
